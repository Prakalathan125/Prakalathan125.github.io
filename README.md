## Run Locally

No framework, package installation, or build step is required.

1. Clone this repository:
   ```bash
   git clone https://github.com/Prakalathan125/Prakalathan125.github.io.git
   ```
2. Open the project folder.
3. Open `index.html` in your browser.

Alternatively, use a local development server in your editor if you prefer.

## Deploy with GitHub Pages

1. Create a **public** GitHub repository named exactly `Prakalathan125.github.io`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and the `/(root)` folder, then click **Save**.
6. After GitHub Pages finishes deploying, visit: https://Prakalathan125.github.io

The live URL may take a few minutes to become available after the first deployment.
